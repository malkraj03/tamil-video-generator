QUICK START GUIDE
================================================================================

1. Install Dependencies (5 minutes)
   $ python3 -m venv venv
   $ source venv/bin/activate
   $ pip install -r requirements.txt
   $ brew install ffmpeg imagemagick

2. Set Up YouTube API (10 minutes)
   - Go to Google Cloud Console
   - Create project, enable YouTube API v3
   - Create OAuth credentials (Desktop app)
   - Download JSON as credentials.json

3. Verify Installation (2 minutes)
   $ ./verify_installation.sh

4. Generate First Video (60 minutes)
   $ python main.py --mode generate

5. Start Scheduler (Runs forever)
   $ python main.py --mode start

================================================================================
USAGE COMMANDS
================================================================================

Generate video immediately:
  $ python main.py --mode generate

Start scheduler (twice daily):
  $ python main.py --mode start

  $ python main.py --mode status

Clean old files:

Run tests:

Verify installation:

Docker deployment:
  $ docker-compose up -d
